# Quiz Application

A console-based Quiz Application developed using Java, JDBC, and MySQL.

## Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

## Features

- Start Quiz
- Multiple-choice questions
- Answer validation
- Score calculation
- Percentage calculation
- Grade calculation
- Pass/Fail status
- Save quiz results to MySQL
- View previous quiz results

## Database

Database Name:

`quiz_db`

Tables:

- `questions`
- `results`

## How It Works

1. User selects Start Quiz.
2. User enters their name.
3. Questions are retrieved from MySQL using JDBC.
4. User selects an answer for each question.
5. The application calculates the score and percentage.
6. Grade and Pass/Fail status are displayed.
7. The result is stored in the MySQL database.
8. Users can view previous results.
